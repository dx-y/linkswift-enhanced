# LinkSwift 增强版

基于 [LinkSwift](https://github.com/hmjz100/LinkSwift)（「网盘直链下载助手」系）二次开发的油猴脚本增强版。在官方原版能力之上，补充日常转存整理工作流所需的多项自动化能力，并持续进行稳定性与可维护性优化。

> 当前版本：**v1.1.11**
> 许可：**AGPL-3.0-or-later**

## 功能简介

- **八大网盘直链获取**：百度网盘 / 阿里云盘 / 中国移动云盘 / 天翼云盘 / 迅雷云盘 / 夸克网盘 / UC网盘 / 123云盘。
- 一键复制直链下载地址，支持多种下载器接管下载。
- 自动转存 / 云添加 / 离线下载的辅助能力，减少重复操作。
- 下载历史记录、下载过滤、批量重命名等日常整理功能。

## 安装

1. 浏览器安装油猴（Tampermonkey）或 Violentmonkey。
2. 打开下面的安装地址，点击「安装」：

   <https://github.com/dx-y/linkswift-enhanced/raw/main/linkswift-enhanced.user.js>

3. 打开目标网盘页面，脚本自动生效。

## 支持的网盘

百度网盘 · 阿里云盘 · 中国移动云盘 · 天翼云盘 · 迅雷云盘 · 夸克网盘 · UC网盘 · 123云盘

## 更新方式

脚本头部已配置 `@updateURL` / `@downloadURL` 指向本仓库，后续发布新版本后油猴会自动检测并提示更新。更新记录见 `CHANGELOG.md`。

## 相对官方原版的改动

### 功能增强（官方版未提供）

| 能力 | 说明 |
| --- | --- |
| 自动转存 / 云添加 / 离线下载 | 识别转存任务后自动切换目标网盘，自动触发「云添加 / 离线下载」并逐条填充链接完成转存 |
| 下载历史 | 记录最近生成的下载任务，便于回查与复用 |
| 下载过滤 | 按关键字 / 后缀名过滤待下载文件 |
| 批量重命名 | 对文件名批量改名后再生成下载链接 |
| 多终端命令 | 一键复制适配不同下载器的命令 |
| 授权增强 | 令牌本地缓存，避免频繁重复授权 |

### 稳定性与维护优化（v1.1.8）

- 清理未调用的死代码，收敛两套冲突的转存存储逻辑为一套统一的存储链路（活跃的自动转存 / 云添加 / 离线下载功能完整保留）。
- 第三方依赖 CDN 切换至 **jsdelivr**，提升加载稳定性。
- 去除重复的匹配规则，修正残留的旧版本注释。


### 稳定性与维护优化（v1.1.9 - v1.1.11）

- 修复迅雷网盘分享链接在 IDM 接管下载时缺少必要请求头的问题。
- 全量修复各网盘 IDM 接管下载：补齐 UA / Referer / Cookie 请求头，增加 RPC 兜底与诊断日志，提升下载器接管稳定性。
- 恢复百度网盘分享页「保存后下载」流程；清理阿里云盘 / 123 云盘重复的「转存到网盘」入口项。
