# LinkSwift（网盘直链下载助手）油猴脚本增强版 — IDMPush增强

基于 [LinkSwift](https://github.com/hmjz100/LinkSwift) 二次开发的油猴脚本增强版。在官方原版能力之上，补充日常转存整理工作流所需的多项自动化能力，并持续进行稳定性与可维护性优化。

> 当前版本：**v1.1.35**
> 许可：**AGPL-3.0-or-later**

## 功能简介

- **多网盘适配**：百度网盘 / 阿里云盘 / 中国移动云盘 / 天翼云盘 / 迅雷云盘 / 夸克网盘 / UC网盘 / 123云盘。
- 便捷获取下载地址，支持配合常用下载工具使用。
- 自动转存 / 云添加 / 离线下载的辅助能力，减少重复操作。
- 下载历史记录、下载过滤、批量重命名等日常整理功能。

## IDM Push 本地接收端（IDMPush.exe）

「推送至 IDM」经由本地接收端 **IDMPush.exe** 中转：油猴脚本 → `127.0.0.1:16888` → IDM 6.43+ 官方命令行 `idman.exe /d` 投递。

### 名字

- **油猴脚本**：`IDMPush增强`（脚本头部 `@name`；仓库内文件名保持 `linkswift-enhanced.user.js` 不变，以维持既有更新链）。
- **本地接收端**：`IDMPush.exe`（约 67MB 单文件，.NET 8 self-contained，GUI 子系统无黑窗）。

### 运行办法

1. 从 Release 下载 **IDMPush.exe**，放到任意目录（建议放在 IDM 安装目录旁，如 `C:\Program Files (x86)\Internet Download Manager\`）。
2. 双击运行一次即可。此后浏览器打开网盘页面时，脚本会在页面加载 800ms 后静默探测接收端（GET /v1/ping）；未运行时通过已注册的 `linkswift://` 协议自动拉起（v1.1.35 起），**无需常驻、无开机自启**。
3. 端口写死 `127.0.0.1:16888`（GET /v1/ping、POST /v1/push），无需任何配置；中文文件名/标题推送实测约 25ms 返回 `ok:true`。
4. 重启电脑后无需手动处理：打开网盘页即自动拉起；用完可随时关闭进程，下次推送会自动再次拉起。

## 安装

1. 浏览器安装油猴（Tampermonkey）或 Violentmonkey。
2. 打开下面的安装地址，点击「安装」：

   <https://github.com/dx-y/linkswift-enhanced/raw/main/linkswift-enhanced.user.js>

3. 打开目标网盘页面，脚本自动生效。

## 最近更新（v1.1.35）

### v1.1.35
- 新增本地接收端按需拉起：注册 `linkswift://` 自定义协议指向 IDMPush.exe，页面加载 800ms 后脚本静默预热（`ensureBridgeWarmup`），接收端未运行自动拉起，无常驻、无自启、无提示。
- 接收端 IDMPush.exe 修复中文推送死锁：body 改为逐字节读取，补齐 CORS 响应与日志；实测中文 push 约 25ms 返回 `ok:true`。
- 接收端发布为单文件（约 67MB），GUI 子系统无黑窗，监听 `127.0.0.1:16888`。

### v1.1.34
- 修复「推送至 IDM」按钮无限转圈：base.get / base.post 增加 8s Promise.race 超时兜底，串行锁不再被挂起请求永久占用。
- 修复 probeBridge / postBridge 响应体 JSON 二次解析。

### v1.1.29
- 修复夸克网盘「推送至 IDM」按钮可能永久卡死的问题：点击 handler 增加 try/catch/finally，推送完成或异常均恢复按钮状态，异常时给出可见错误提示。
- 修复 IDM 串行推送锁被异常污染导致后续推送全部失败的问题。
- 补充 @connect 127.0.0.1 显式声明，规避部分油猴管理器对本地回环地址连接的白名单差异。
- 修复文件名含特殊字符（" & < > '）时推送链接损坏的问题，增加 HTML 转义。
- 修复全局菜单取链失败时卡在「获取中」无提示的问题。
- 新增「下载助手」主菜单「推送 IDM」入口。

### v1.1.28
- 新增 IDM 扩展 SW 自动唤醒：推送失败时脚本通过 history.pushState 触发 IDM 扩展注册的 webNavigation 事件，自动唤醒休眠的扩展 Service Worker 并重建会话，免去手动点击工具栏 IDM 图标（Chrome MV3 版扩展专用；Edge 版为常驻后台页不受影响）。

### v1.1.27

- 修复 123 网盘个人盘/分享页勾选文件后提示"请勾选要下载的文件哦~"的问题。
- getSelectedList 容器选择器补入新版类名 mfy_h-table-module，支持向上两层 fiber 兜底。

### v1.1.20

- 修复「IDM 服务未就绪」误报：IDM 服务在线但无 Client 会话时准确识别 HTTP 404 并提示激活扩展会话，不再进入 120 秒等待。
- 优化响应体为空时透传 HTTP 状态码，404 不再误判为服务未就绪。
- 优化等待重试前先探测可用 Client ID，全部 404 时直接给出可执行指引。

### 稳定性与维护优化（v1.1.8）

- 清理未调用的死代码，收敛两套冲突的转存存储逻辑为一套统一的存储链路（活跃的自动转存 / 云添加 / 离线下载功能完整保留）。
- 第三方依赖 CDN 切换至 **jsdelivr**，提升加载稳定性。
- 去除重复的匹配规则，修正残留的旧版本注释。


### 稳定性与维护优化（v1.1.9 - v1.1.11）

- 修复迅雷网盘分享链接在 IDM 接管下载时缺少必要请求头的问题。
- 全量修复各网盘 IDM 接管下载：补齐 UA / Referer / Cookie 请求头，增加 RPC 兜底与诊断日志，提升下载器接管稳定性。
- 恢复百度网盘分享页「保存后下载」流程；清理阿里云盘 / 123 云盘重复的「转存到网盘」入口项。

### 稳定性与维护优化（v1.1.12 - v1.1.14）

- 修复 IDM 推送偶发「发送失败!」：新增 Client ID 自动探测（`probeIDMClient`）与会话自愈（`diagnoseIDMFailure` / `recoverIDMSession`），推送失败自动重连扩展 WebSocket 会话并自动重推，无需手动改配置。
- 修复多盘同时推送因配置漂移导致的 `client/undefined` 问题。
- 新增 Hydra 下载管理器支持（各网盘下载下拉菜单可选，经本地中转桥推送）。
