# LinkSwift 增强版

基于 [LinkSwift](https://github.com/hmjz100/LinkSwift) 二次开发的油猴脚本增强版。在原有能力之上，补充日常转存整理工作流所需的多项自动化能力，并持续进行稳定性与可维护性优化。

> 当前版本：**v1.1.37**
> 许可：**AGPL-3.0-or-later**

## 功能简介

- **多网盘适配**：百度网盘 / 阿里云盘 / 中国移动云盘 / 天翼云盘 / 迅雷云盘 / 光鸭云盘 / 夸克网盘 / UC网盘 / 123云盘。
- 便捷获取下载地址，支持配合常用下载工具使用。
- 自动转存 / 云添加 / 离线下载的辅助能力，减少重复操作。
- 下载历史记录、下载过滤、批量重命名等日常整理功能。
- 123 云盘可查看客户端下载进度与速度，直链额度不足时提示剩余额度。

## IDM Push 本地接收端（可选）

「推送至 IDM」经由本地接收端中转：油猴脚本 → `127.0.0.1:16888` → IDM，可携带 Referer / Cookie，夸克、123 等需要请求头的直链也能正常下载。

> 不装也能用：接收端不可用时会自动降级为「复制 IDM 命令到剪贴板」，`Win+R` 粘贴回车同样能导入 IDM。
> 只有夸克 / 123 这类必须带请求头的直链才推荐装接收端。

### 三步装好（一次即可，不需要安装 Node / .NET 等任何环境）

1. **下载**：[`IDMPush.exe`](https://github.com/dx-y/linkswift-enhanced/releases/latest/download/IDMPush.exe)（约 63 MB，单文件，免安装）
2. **双击运行一次**：自动注册 `linkswift://` 协议、自动找到 `IDMan.exe`、写好配置，弹一个「配置完成」提示框，点确定关闭即可（**不需要保持运行**）。
3. 回到网盘页面点「推送至 IDM」，脚本会自动唤起接收端，空闲 120 秒自动退出。

> 接收端**不常驻、不开机自启、不需要管理员权限、只监听 `127.0.0.1`**，且只接受本脚本的请求。
> 若提示找不到 IDM：`IDMPush.exe --idm "C:\Program Files (x86)\Internet Download Manager\IDMan.exe"`。

详细说明见 [`docs/idm-receiver.md`](docs/idm-receiver.md)。

## 安装

1. 浏览器安装油猴（Tampermonkey）或 Violentmonkey。
2. 打开下面的安装地址，点击「安装」：

   <https://github.com/dx-y/linkswift-enhanced/raw/main/linkswift-enhanced.user.js>

3. 打开目标网盘页面，脚本自动生效。

## 我们优化改进了什么

### 功能增强

| 能力 | 说明 |
| --- | --- |
| 自动转存 / 云添加 / 离线下载 | 识别转存任务后自动切换目标网盘，自动触发「云添加 / 离线下载」并逐条填充链接完成转存 |
| 下载历史 | 记录最近生成的下载任务，便于回查与复用 |
| 下载过滤 | 按关键字 / 后缀名过滤待下载文件 |
| 批量重命名 | 对文件名批量改名后再生成下载链接 |
| 多终端命令 | 一键复制适配不同下载器的命令 |
| 推送 IDM（本地接收端） | 可携带 Referer / Cookie，需要请求头的直链也能交给 IDM 下载 |
| 下载方式开关 | 九种下载方式可分别开关，九个网盘统一生效 |
| 123 客户端面板 | 查看客户端下载进度与速度，额度不足时提示剩余额度 |

### 稳定性与性能（v1.1.37）

- 页面监听开销大幅降低，长时间挂着页面不卡。
- 主题换色不再卡死或占用内存；下载按钮出问题会自动恢复。
- 下载历史兼容旧数据，记录可正常删除。
- 各网盘按钮位置、菜单展开、勾选识别、报错提示的适配问题已修复。

### 稳定性与维护优化（v1.1.8 - v1.1.14）

- 清理未调用的死代码，收敛两套冲突的转存存储逻辑为一套统一的存储链路（自动转存 / 云添加 / 离线下载功能完整保留）。
- 第三方依赖 CDN 切换至 jsdelivr，提升加载稳定性。
- 全量修复各网盘 IDM 接管下载：补齐 UA / Referer / Cookie 请求头，增加 RPC 兜底与诊断日志。
- 新增 Client ID 自动探测与会话自愈，推送失败自动重连并重推。
- 新增 Hydra 下载管理器支持。
