## 推送至 IDM 需要本地接收端（可选，但推荐）

脚本本身的「获取直链 / 复制链接 / 保存到网盘」等功能**不需要**接收端，装完就能用。

只有 **「推送至 IDM」** 这一项需要经过本机的一个小程序中转（脚本 → `127.0.0.1:16888` → IDM），
这样才能带上 Referer / Cookie —— 夸克、123 这类必须有请求头的直链才推得动。

### 三步装好（一次即可，不需要安装任何环境）

1. **下载**：[`IDMPush.exe`](https://github.com/dx-y/linkswift-enhanced/releases/latest/download/IDMPush.exe)（约 63 MB 单文件）
2. **双击运行一次**：它会自动完成——注册 `linkswift://` 协议、自动找到你的 `IDMan.exe`、写入配置，
   然后弹一个「配置完成」提示框，点确定就关掉，**不需要保持运行**。
3. 回到网盘页面点 **「推送至 IDM」**：脚本会自动唤起接收端并推送，用完自动退出。

### 它不会做什么（可以放心）

- **不常驻**：空闲 120 秒自动退出；
- **不开机自启**：不写任何启动项、不加计划任务、不注册服务；
- **不联网**：只监听 `127.0.0.1:16888`，只接受本脚本的请求（校验 `X-LS-Client` 头），拒绝一切网页跨域预检；
- **不需要管理员权限**：协议注册写在当前用户注册表 `HKCU` 下。

### 找不到 IDM 怎么办

如果双击后提示"没找到 IDMan.exe"，说明 IDM 没装或装在非标准位置。重新运行一次并指定路径：

```
IDMPush.exe --idm "C:\Program Files (x86)\Internet Download Manager\IDMan.exe"
```

> 不想装接收端也没关系：接收端不可用时会自动降级为「复制 IDM 命令到剪贴板」，按 `Win+R` 粘贴回车同样能导入 IDM，
> 只是夸克 / 123 这类需要请求头的直链可能失败。
>
> 进阶用户如果本机已有 Node.js，也可以用 Release 里的 `bridge-server.js`（约 28 KB，源码可审计），
> 功能等价：`node bridge-server.js --setup`。
