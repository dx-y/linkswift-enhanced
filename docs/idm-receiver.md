## 推送至 IDM 需要本地接收端（可选）

脚本本身的「获取直链 / 复制链接」等功能**不需要**接收端，装完就能用。
只有 **「推送至 IDM」** 这一项需要经过本机的一个小程序中转（脚本 → `127.0.0.1:16888` → IDM），
这样才能带上 Referer / Cookie，夸克、123 这类必须有请求头的直链才推得动。

### 三步装好（一次即可）

1. **下载**：<https://github.com/dx-y/linkswift-enhanced/releases/download/v1.1.35/IDMPush.exe>（约 64 MB，单文件绿色版）
2. **双击运行一次**：会自动注册 `linkswift://` 协议；如果提示找不到 IDM，把 `IDMan.exe` 的完整路径填进去即可。
3. 回到网盘页面点 **「推送至 IDM」**：脚本会自动唤起接收端并完成推送，之后无需再管它。

> 不想装也没关系：接收端不可用时会自动降级为「复制 IDM 命令到剪贴板」，按 `Win+R` 粘贴回车同样能导入 IDM，
> 只是夸克 / 123 这类需要请求头的直链可能失败。
>
> 端口固定 `127.0.0.1:16888`，只监听本机、不对外开放；不常驻、不自启。
